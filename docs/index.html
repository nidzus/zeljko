Zeljko, the jyotisha advisor

Ask about a decision — take the job, move, commit, wait — and get a plain answer from your computed Vedic chart, inside your own Claude. It keeps a journal of what it advised and how things turned out.

Install it in four steps

1

Have Claude Desktop

Zeljko is an add-on for the Claude app on your computer. If you do not have the app yet, get it from claude.ai/download, install it and sign in. It does not work in the Claude website or the phone app.

2

Download Zeljko for your computer

WindowsWindows 10 or 11 MacApple chip (M1 and later) MacIntel chip

Not sure which Mac you have? Click the Apple menu at the top left, then About This Mac. If it says “Chip: Apple M…” take the first Mac file; if it says “Processor: … Intel” take the second.

The file is about 100 MB, because it carries everything it needs. Nothing else has to be installed.

3

Open the file you downloaded

Double-click it. Claude Desktop opens and shows Zeljko with an Install button. Click it.

Claude shows a warning that the extension can access your computer and that its maker has not been verified by Anthropic. It shows this for every extension that is not from its own catalogue. It is expected here: Zeljko is free software made by one person, and its code is public.

If it shows two boxes for folders, leave both empty. There is nothing else to set up.

If double-clicking does nothing: right-click the file, choose Open with, and pick Claude.

4

Say hello

Start a new chat in Claude Desktop and type:

Set me up with Zeljko.

It will ask when and where you were born, how sure you are of the time, and for a few dated events from your life. Then you can ask it things.

Claude asks your permission the first time it uses each of Zeljko’s tools. Click Always allow, not “Allow once”, and it stops asking about that tool. After the first few questions the boxes are gone.

If Claude does not seem to know what Zeljko is: open Claude Desktop’s Settings, choose Customize, then Connectors, click Zeljko, the jyotisha advisor and make sure its switch is on. Then start a new chat.

Things you can say

Should I accept the offer, or wait until next year?
Is this week a good one to sign the contract?
Why have the last two years been so heavy?
Add my partner.
Show me what you advised before, and let me tell you how it went.
My birth year is wrong, it should be 1976.
Back up my data.
Remove my brother’s profile.

What to expect from it

  • The answer first, in plain words, then the timing, then the reasoning, with each technical term explained as it comes up.
  • The astronomy is calculated, not guessed. Positions and dates come from the Swiss Ephemeris running on your computer. Claude interprets them; it never makes up a number.
  • It is honest about your birth time. If you only know it roughly, it refuses the claims that depend on the exact minute instead of pretending.
  • It is blunt. Difficult periods are described as plainly as good ones.

This is a tool for thinking a decision through. It is not medical, legal, financial or any other professional advice, and it can be wrong.

Your data

  • Your birth details, life events and journal are stored in one folder on your own computer (normally jyotisha-data in your home folder). The extension sends them nowhere and has no account or server of its own.
  • Claude itself sees what you discuss with it, exactly as with anything else you type into Claude.
  • Before a profile is corrected or removed, a copy of your data is set aside automatically in that folder, so a mistake can be undone.
  • Say “back up my data” now and then. For protection against the computer failing, say where the copy should go, for example “back up my data to my USB stick”.

Updating and removing

To update, download the newest file from this page and open it the same way. Your data is not touched. To remove Zeljko, uninstall it in Claude Desktop (Settings → Customize → Connectors → Zeljko → Uninstall); your data folder stays until you delete it yourself.
